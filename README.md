# ✨ What is MetaLeadIQ?

**MetaLeadIQ** is an AI-powered lead scoring and omnichannel prioritization system designed to help sales teams identify and act on the leads that matter most.

The system combines:

- 🤖 Machine Learning Lead Scoring
- 📈 Platt Probability Calibration
- ⏱️ Exponential Lead Decay
- 📊 Confidence Intervals
- 💬 WhatsApp & Instagram Integration
- 🔄 Omnichannel Lead Ingestion
- 🔐 Contact Score Freezing
- 📋 Priority-Based Lead Queues
- 📊 Performance Analytics

The portfolio website transforms these technical concepts into an **interactive presentation designed for project demonstrations, evaluations, and viva/pitch sessions**.
